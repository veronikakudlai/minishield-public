# นโยบายความเป็นส่วนตัวของ MiniShield

**วันที่มีผลบังคับใช้:** 5 พฤศจิกายน 2026  
**ปรับปรุงล่าสุด:** 10 พฤศจิกายน 2026  
**ติดต่อเรื่องความเป็นส่วนตัว:** [privacy_policy.ios@proton.me](mailto:privacy_policy.ios@proton.me)  
**ฝ่ายสนับสนุน:** [GitHub Issues](https://github.com/veronikakudlai/minishield-public/issues)

### 1. บทนำ

นโยบายนี้อธิบายการจัดการข้อมูลของ MiniShield ซึ่งเป็นแอปและส่วนขยาย Safari ที่ช่วยลดโฆษณา คำขอติดตาม แบนเนอร์คุกกี้ และองค์ประกอบที่รบกวนการใช้งาน ไม่จำเป็นต้องลงทะเบียนหรือสร้างบัญชีผู้ใช้

### 2. ข้อมูลที่ใช้ภายในอุปกรณ์

MiniShield จัดเก็บสถานะการป้องกัน โหมดและตัวเลือกที่คุณเลือกไว้ในอุปกรณ์ รวมถึงรายการยกเว้นการป้องกันทั้งเว็บไซต์ รายการยกเว้นเฉพาะการจัดการแบนเนอร์คุกกี้ และรายการยกเว้นเพื่อความเข้ากันได้ของเว็บไซต์ (ปิดการซ่อนด้วย CSS แบบเนทีฟ) นอกจากนี้ยังเก็บกฎตัวกรอง เวอร์ชัน ค่าแฮชสำหรับตรวจสอบ ข้อมูลการอัปเดตและย้อนกลับ และสถานะการใช้การตั้งค่า

เมื่อคุณอนุญาตให้เข้าถึงเว็บไซต์ใน Safari ส่วนขยายอาจตรวจสอบที่อยู่ของหน้าที่เปิด โครงสร้าง DOM คุณลักษณะขององค์ประกอบ ข้อความบนปุ่ม และสัญญาณบางอย่างเกี่ยวกับคุกกี้เพื่อระบุแบนเนอร์หรือข้อความเชิญให้เข้าสู่ระบบที่ไม่จำเป็น การตรวจสอบทำภายในอุปกรณ์และไม่ส่งข้อมูลหน้าเว็บให้ผู้พัฒนา MiniShield ไม่เก็บประวัติการท่องเว็บแบบรวมศูนย์ และไม่มี SDK วิเคราะห์พฤติกรรมหรือ SDK ติดตามเพื่อโฆษณา

### 3. การจัดเก็บและการสำรองข้อมูล

การตั้งค่า รายการยกเว้น และกฎจะถูกจัดเก็บในพื้นที่ App Group ภายในอุปกรณ์ ซึ่งแอปและส่วนขยายใช้ร่วมกัน ไม่มีการซิงค์ข้อมูลเหล่านี้ผ่านเซิร์ฟเวอร์ของผู้พัฒนา ขึ้นอยู่กับการตั้งค่า iOS ข้อมูลบางส่วนอาจรวมอยู่ในการสำรองข้อมูลอุปกรณ์ โดย MiniShield ไม่ได้ควบคุมการสำรองข้อมูลนั้น

### 4. วัตถุประสงค์ในการใช้ข้อมูล

ข้อมูลภายในอุปกรณ์ใช้เพื่อให้บริการคุณสมบัติที่คุณเลือกเท่านั้น ได้แก่ การกรองคำขอ การตรวจจับและจัดการองค์ประกอบหน้าเว็บ การลบพารามิเตอร์ติดตามที่รู้จักออกจากลิงก์ภายในอุปกรณ์ การจัดการรายการยกเว้น การตรวจสอบ การอัปเดต และการกู้คืนกฎ MiniShield ไม่ขายประวัติการเข้าชม ไม่สร้างโปรไฟล์โฆษณา และไม่ใช้เนื้อหาหน้าเว็บเพื่อแสดงโฆษณาเฉพาะบุคคล

### 5. แบนเนอร์คุกกี้และการดำเนินการบนหน้าเว็บ

กฎของ Safari อาจบล็อกสคริปต์แบนเนอร์คุกกี้บางชนิดได้ หากแบนเนอร์ยังปรากฏอยู่ MiniShield จะพยายามซ่อนอย่างปลอดภัยก่อน **เมื่อซ่อนสำเร็จ จะไม่มีการกดปฏิเสธคุกกี้อัตโนมัติสำหรับแบนเนอร์นั้น** หากแบนเนอร์ยังแสดงอยู่ และเปิดใช้คุณสมบัติที่เกี่ยวข้อง MiniShield อาจพยายามปฏิเสธคุกกี้ที่ไม่จำเป็นในกรณีที่รองรับ พร้อมตรวจสอบผลลัพธ์ เว็บไซต์อาจไม่ได้บันทึกตัวเลือกดังกล่าว การซ่อนแบนเนอร์ไม่ได้หมายความว่าคุกกี้ถูกปฏิเสธหรือหยุดการติดตามทั้งหมด

### 6. สิทธิ์การเข้าถึง เครือข่าย และบุคคลภายนอก

ส่วนขยาย Safari ต้องได้รับอนุญาตสำหรับเว็บไซต์ที่คุณเลือก ใช้การสื่อสารกับแอปหลักและความสามารถของแท็บปัจจุบัน คุณจัดการสิทธิ์เหล่านี้ รวมถึงการใช้งานในโหมดส่วนตัว ผ่าน Safari เมื่อตรวจสอบหรือดาวน์โหลดการอัปเดตกฎด้วยตนเอง MiniShield จะเชื่อมต่อผ่าน HTTPS ไปยังบริการโฮสต์ภายนอก รวมถึงบริการของ GitHub ผู้ให้บริการเหล่านั้นอาจประมวลผลที่อยู่ IP เวลาเรียกใช้ และข้อมูลทางเทคนิคของ HTTP ตามนโยบายของตน โดยคำขออัปเดตไม่แนบประวัติการเข้าชม เนื้อหาหน้าเว็บ หรือการตัดสินใจเกี่ยวกับการยินยอมคุกกี้ iOS, App Store และบริการสำรองข้อมูลอาจประมวลผลข้อมูลของตนเองแยกต่างหาก

### 7. การควบคุม ระยะเวลาเก็บ และการลบ

คุณสามารถเปลี่ยนโหมด ปิดคุณสมบัติ ลบรายการยกเว้น หรือปิดส่วนขยาย Safari ได้ กฎที่จัดเก็บในเครื่องและข้อมูลสำหรับย้อนกลับจะคงอยู่จนกว่าจะถูกแทนที่หรือลบ การถอนการติดตั้งโดยทั่วไปจะลบข้อมูลแอปในเครื่องตามกลไกของ iOS แต่ข้อมูลสำรองหรือข้อมูลที่บุคคลภายนอกจัดเก็บไว้อาจยังคงอยู่ ผู้พัฒนาไม่มีสำเนาประวัติการเข้าชมที่เก็บบนเซิร์ฟเวอร์เพื่อส่งออกหรือลบตามคำขอ

### 8. ความปลอดภัยและข้อจำกัด

การอัปเดตกฎคุกกี้ที่มีลายเซ็นจะถูกตรวจสอบด้วยลายเซ็นดิจิทัลและค่าแฮช ส่วนการอัปเดตรายการโดเมนจะถูกตรวจสอบด้วยค่าแฮชจากแหล่งที่มาและการตรวจสอบรูปแบบก่อนใช้งาน และอาศัยมาตรการความปลอดภัยของอุปกรณ์ แต่ไม่สามารถรับประกันความปลอดภัยได้อย่างสมบูรณ์ MiniShield ทำงานเฉพาะใน Safari ไม่ใช่ VPN พร็อกซี หรือบริการไม่เปิดเผยตัวตน

### 9. การเปลี่ยนแปลงนโยบาย

นโยบายนี้อาจได้รับการปรับปรุงเมื่อคุณสมบัติ วิธีจัดการข้อมูล หรือข้อกำหนดที่เกี่ยวข้องเปลี่ยนไป ฉบับล่าสุดจะเผยแพร่ผ่านลิงก์ทางการของแอป หากกฎหมายหรือกฎของแพลตฟอร์มกำหนด จะมีการแจ้งการเปลี่ยนแปลงที่สำคัญ

### 10. การติดต่อ
